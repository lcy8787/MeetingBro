# Start MeetingBro

**Start the backend first, then the frontend.**

## Backend

```bash
conda activate MeetingBro
cd app/backend
meetingbro-backend
```

## Frontend (new terminal)

```bash
cd app/frontend
npm run dev
```

The Electron window will open automatically.

# 啟動 MeetingBro

**先開後端，再開前端。**

## 後端

```bash
conda activate MeetingBro
cd app/backend
meetingbro-backend
```

## 前端（新終端機）

```bash
cd app/frontend
npm run dev
```

Electron 視窗會自動彈出。
